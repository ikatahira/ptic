Estrutura Sequencial — A Base de Tudo

➡️
A estrutura sequencial é a mais simples: as instruções são executadas uma por uma, na ordem em que aparecem, de cima para baixo.

Exemplo em pseudocódigo:
INICIO
LEIA comprimento, largura
area = comprimento * largura
perimetro = 2 * (comprimento + largura)
ESCREVA "Área:", area
ESCREVA "Perímetro:", perimetro
FIM

Regra fundamental: a ordem importa! Se você calcular perimetro antes de ler os valores, o programa vai usar lixo de memória. Em programação, a sequência é lei!

Variáveis e Operadores — Blocos Básicos dos Algoritmos

🔢
Variável é um espaço na memória do computador com um nome e um valor que pode mudar.

Tipos de variáveis:
• Inteiro: números sem decimal (ex: 5, -3, 100)
• Real/Float: números com decimal (ex: 3.14, 9.8, -0.5)
• Texto/String: palavras e frases (ex: "Olá", "João")
• Lógico/Booleano: só Verdadeiro ou Falso

Operadores matemáticos:
+ soma | - subtração | * multiplicação | / divisão | % resto | ** potência

Atribuição: x = 5 significa "a variável x RECEBE o valor 5".

Entrada e Saída de Dados

📐
Todo algoritmo tem pelo menos uma entrada (dados que recebe) e uma saída (resultado que produz).

Em pseudocódigo:
LEIA nome, idade ← entrada (usuário digita)
ESCREVA "Olá,", nome ← saída (mostra resultado)

Em linguagens reais:
• Python: nome = input("Seu nome: ") e print("Olá,", nome)
• JavaScript: let nome = prompt("Seu nome:") e alert("Olá " + nome)

Dica importante: variáveis que vêm do usuário (LEIA) são a entrada do seu programa. Variáveis calculadas que você mostra (ESCREVA) são a saída.
⚡ +10 XP
✏️ Comando que exibe um resultado para o usuário em pseudocódigo é:
ESCREVA

Algoritmos de Cálculo — Sequencial na Prática

🧮
Algoritmos sequenciais são perfeitos para cálculos matemáticos simples.

Exemplo — Calcular troco:
INICIO
LEIA preco_produto, valor_pago
troco = valor_pago - preco_produto
SE troco >= 0 ENTAO
ESCREVA "Troco: R$", troco
SENAO
ESCREVA "Valor insuficiente!"
FIM

Calcular média: media = (n1 + n2 + n3) / 3
Calcular desconto: preco_final = preco * (1 - desconto/100)
Converter temperatura: celsius = (fahrenheit - 32) * 5 / 9

Projeto Extra — Ordenando com LEDs (Simulador Arduino)

🔌
Aqui está a estrutura sequencial saindo da tela e virando hardware de verdade: um Arduino Uno com 4 LEDs executa, passo a passo e em ordem — sequencialmente! — o algoritmo de Ordenação por Seleção.

Como funciona:
🟡 LED piscando = essa posição está sendo comparada agora
🟢 LED aceso fixo = essa posição já está ordenada (não muda mais)

Clique em "Iniciar Simulação" para ver a animação — é exatamente isso que os LEDs físicos do Arduino vão fazer.
1
Em cada rodada, procure o menor valor
O Arduino olha só para as posições que ainda não foram ordenadas e tenta descobrir qual delas tem o menor valor.
2
Compare posição por posição
Para descobrir o menor valor, ele acende brevemente o LED de cada posição candidata, uma de cada vez — é o LED piscando em amarelo que você vê na animação.
3
Troque e fixe a posição
Encontrado o menor valor da rodada, o Arduino troca os valores (se precisar) e acende o LED daquela posição em verde — ela já está no lugar certo e não muda mais.
4
Repita até sobrar só a última posição
O processo se repete para as posições restantes. Quando sobra só uma posição, ela já está ordenada automaticamente — não precisa nem comparar.

📋 Código completo — cole no Arduino IDE
// VERSAO FINAL: visualizacao automatica da ordenacao por selecao
// Pinos: LED pos.0=2, pos.1=3, pos.2=4, pos.3=5 (sem botoes - use o RESET do Arduino para repetir)

const int LEDS[4] = {2, 3, 4, 5};
int vetor[4] = {26, 8, 35, 1}; // valores de exemplo (ajuste os cartoes fisicos para bater com esses numeros)

void setup() {
  for (int i = 0; i < 4; i++) pinMode(LEDS[i], OUTPUT);

  Serial.begin(9600);
  Serial.println("Vetor inicial:");
  imprimirVetor();

  delay(1500); // pausa inicial com tudo apagado, antes de comecar
  ordenarPorSelecao();
}

void loop() {
  // nao faz nada aqui: a ordenacao ja rodou uma vez dentro do setup()
  // para rodar de novo, aperte o botao RESET do proprio Arduino
}

void ordenarPorSelecao() {
  for (int i = 0; i < 3; i++) {
    int menor = i;

    Serial.print("Rodada ");
    Serial.println(i);

    // varre as posicoes candidatas desta rodada, comparando uma por uma
    for (int j = i + 1; j < 4; j++) {
      digitalWrite(LEDS[j], HIGH); // acende: "comparando esta posicao agora"
      Serial.print("  Comparando posicao ");
      Serial.print(j);
      Serial.print(" (valor ");
      Serial.print(vetor[j]);
      Serial.println(")");
      delay(700);
      digitalWrite(LEDS[j], LOW); // apaga depois de comparar

      if (vetor[j] < vetor[menor]) {
        menor = j;
      }
    }

    if (menor != i) {
      trocar(i, menor);
    }

    digitalWrite(LEDS[i], HIGH); // fica aceso PARA SEMPRE: esta posicao ja esta ordenada
    Serial.print("Posicao ");
    Serial.print(i);
    Serial.println(" ordenada.");
    delay(600);
  }

  // a ultima posicao sempre fica ordenada automaticamente
  digitalWrite(LEDS[3], HIGH);

  Serial.println("Vetor ordenado!");
  imprimirVetor();
}

void trocar(int a, int b) {
  int temp = vetor[a];
  vetor[a] = vetor[b];
  vetor[b] = temp;

  Serial.println("  Troca de valores! Lembre de trocar os cartoes fisicos tambem.");
}

void imprimirVetor() {
  for (int i = 0; i < 4; i++) {
    Serial.print(vetor[i]);
    Serial.print(" ");
  }
  Serial.println();
}
